# TekaTech

A multi-page static website for TekaTech, a school that teaches children AI, robotics and coding.

**Pages:** home, programs, blog, feedback and contact.

**Built with:** HTML, CSS and vanilla JavaScript (`scripts/main.js` handles the interactive parts). It has no build step and no dependencies.

## Run it

Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8000
```

Then visit http://localhost:8000.
